Quick start



1) Create venv and install:



   python -m venv .venv

   .venv\Scripts\activate

   pip install -r requirements.txt



   Or: .\.venv\Scripts\pip.exe install -r requirements.txt



2) Backtest (Yahoo NSE data, no broker):



   .\.venv\Scripts\python.exe scripts\run_backtest.py --strategy mean_reversion --symbol SBIN --start 2018-01-01



   Portfolio (4 stocks, Rs 20k):



   .\.venv\Scripts\python.exe scripts\run_portfolio_backtest.py --capital 20000 --symbols ICICIBANK,ITC,RELIANCE,TCS --start 2018-01-01



   Dashboard: streamlit run dashboard/app.py



3) Angel One live trading (credentials.py required)



   Check connection + balance:



   .\.venv\Scripts\python.exe scripts\validate_angel_setup.py



   Dry-run one cycle (signals only, NO real orders):



   .\.venv\Scripts\python.exe scripts\run_live_trading.py --capital 20000 --symbols ICICIBANK,ITC,RELIANCE,TCS



   REAL orders (only after you understand the risk):



   $env:ENABLE_LIVE_TRADING="1"

   $env:LIVE_TRADING_CONFIRM="I_UNDERSTAND_REAL_MONEY"

   .\.venv\Scripts\python.exe scripts\run_live_trading.py --live --capital 20000



   Run once per day after market close (3:30 PM IST) or before next open.

   Whitelist EC2 IP <EC2_PUBLIC_IP> on Angel SmartAPI app.

   Dry-run dynamic mode:

   .\.venv\Scripts\python.exe scripts\run_live_trading.py --mode dynamic --capital 20000

   Build / refresh watchlist (ranks Nifty 100 by backtest, keeps top 50):

   .\.venv\Scripts\python.exe scripts\build_watchlist.py --universe nifty100 --top 50 --start 2018-01-01

4) EC2 auto-trading (09:00-15:30 IST, dynamic 4 slots):

   powershell -File scripts\deploy_to_ec2.ps1

   Logs on server: ~/algoTrade/logs/live_service.log

5) Public live log dashboard (orders, P&L, holdings):

   Local:  streamlit run dashboard/live_log.py

   EC2:    http://<EC2_PUBLIC_IP>:8501  (open port 8501 in AWS security group)

   Optional password in .env:  DASHBOARD_PASSWORD=your_secret

   Refresh snapshot: .\.venv\Scripts\python.exe scripts\export_dashboard_snapshot.py

No API keys required for backtests only.
